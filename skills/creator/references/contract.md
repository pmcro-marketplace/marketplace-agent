# Marketplace Creator Contract

Agent: `@marketplace-agent`  
Plugin: `marketplace`  
Skill/Subagent: `creator`

Function:

- `create-marketplace` -> `/marketplace:creator:create-marketplace`

Creation requires:
1. discovery evidence proving a genuine gap,
2. a supported source type,
3. real source/container creation or verification,
4. initialized marketplace catalog,
5. catalog validation evidence.

Plugin package creation is out of scope and belongs to Plugin Agent.
